# 이미지 교체 가이드

현재 포함된 이미지는 모두 가상의 포트폴리오용 생성 이미지입니다. 같은 파일명으로 교체하면 HTML 수정 없이 바로 반영됩니다.

| 파일명 | 권장 비율 | 사용 위치 |
| --- | --- | --- |
| `hero.jpg` | 4:3 또는 3:2, 1800px 이상 | 첫 화면 Hero, 공간 갤러리 |
| `doctor-01.jpg` | 4:5 세로, 1200px 이상 | 대표원장 소개 |
| `facility-01.jpg` | 4:3 또는 3:2, 1600px 이상 | 병원 소개, 건강검진, 갤러리 |
| `facility-02.jpg` | 3:2, 1600px 이상 | 시설 갤러리 진료실 |
| `facility-03.jpg` | 3:2, 1600px 이상 | 시설 갤러리 회복 라운지 |
| `treatment-01.jpg` | 4:5, 1200px 이상 | 피부 클리닉 카드 |
| `treatment-02.jpg` | 4:5, 1200px 이상 | 안티에이징 카드 |

교체할 때는 이미지 속 글자나 워터마크가 없는 사진을 권장합니다. WebP를 사용하려면 HTML의 해당 `.jpg` 파일명도 함께 `.webp`로 바꿔 주세요.
